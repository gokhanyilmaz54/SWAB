# T-001: Solution scaffold and CI

- Depends on: -
- Developer model: sonnet
- Test model: haiku
- Review: none
- Human gate: no

## Goal
Create the buildable solution and quality settings.

## Scope
- Create `Swab.sln`, MVC project `src/Swab.Web`, test project `tests/Swab.Tests`, targeting net10.0.
- Add `global.json` (SDK 10.0.100, rollForward latestFeature), `.editorconfig`, `Directory.Build.props` (nullable on, warnings as errors, NuGet audit on, lock files on).
- Keep template Bootstrap, jQuery and validation under `wwwroot/lib`; remove sample pages.
- Add `.github/workflows/ci.yml`: restore, build, test with a SQL Server service, and fail on high or critical vulnerable packages.
- Commit no secrets; add `appsettings.json` with only non-secret defaults.
- CI uses `permissions: contents: read`, never `pull_request_target`, and runs a SQL Server 2025 service container with a generated throwaway password.
- Add `.github/dependabot.yml` for NuGet and GitHub Actions; pin third-party actions by commit SHA.

## Acceptance criteria
- [ ] `dotnet build -warnaserror` and `dotnet test` pass on a clean clone.
- [ ] A smoke test gets HTTP 200 from a public route.
- [ ] CI YAML references no secret values.
- [ ] Packages are only those approved in PLAN section 3.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
