# T-005: Turkish layout and localization

- Depends on: T-001
- Developer model: sonnet
- Test model: haiku
- Review: none
- Human gate: no

## Goal
Create the shared Turkish UI shell.

## Scope
- Set `tr-TR` culture and Europe/Istanbul display helper.
- Build `_Layout` with navbar, footer, validation messages, Turkish status pages for 403 and 404, and a public home page.
- Translate model validation default messages to Turkish.
- Use a clean, accessible Bootstrap design with no inline scripts.

## Acceptance criteria
- [ ] HTML declares `lang="tr"` and UTF-8, and Turkish characters render correctly.
- [ ] Validation and error pages show Turkish messages.
- [ ] Pages work at phone width with no horizontal scrolling.
- [ ] A test confirms `i` and `I` handling in normalization is invariant under `tr-TR`.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
