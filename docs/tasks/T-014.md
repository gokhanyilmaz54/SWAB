# T-014: Admin user management

- Depends on: T-011, T-012
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Let admins manage users.

## Scope
- Add a paged, searchable user list and detail page with parameterized search.
- Add lock, unlock, resend confirmation, reset 2FA, and grant or revoke Admin.
- Require the admin's password again for role changes and 2FA reset. Log each action with both UserIds.

## Acceptance criteria
- [ ] Only admins can use every action, including direct POST.
- [ ] The last admin cannot be demoted, locked or deleted; admins cannot demote or lock themselves.
- [ ] Locking ends the target's sessions.
- [ ] Search input is safe against SQL injection, including `%` and `_` as literals.
- [ ] Admins never see password hashes, tokens, or 2FA secrets.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
