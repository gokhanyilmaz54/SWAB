# T-021: Data subject rights

- Depends on: T-015, T-020
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Support KVKK access and erasure requests.

## Scope
- Add download of own data as JSON: profile, consents, replies.
- Add account deletion with password and 2FA check: anonymize the user row, remove secrets and roles, end sessions, show replies as `Silinmiş kullanıcı`.
- Add configurable log retention, and document it in the privacy template.
- Show KVKK application contact on the account page.

## Acceptance criteria
- [ ] Users can export and delete only their own data.
- [ ] After deletion the old e-mail is free, sign-in fails, and no personal data remains in Users.
- [ ] The last admin cannot delete their account.
- [ ] Export has no password hash or secrets, and has `no-store`.
- [ ] Deletion is logged only by UserId.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
