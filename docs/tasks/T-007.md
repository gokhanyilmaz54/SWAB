# T-007: E-mail service

- Depends on: T-001, T-003
- Developer model: sonnet
- Test model: haiku
- Review: none
- Human gate: no

## Goal
Send Turkish e-mails safely.

## Scope
- Add `IEmailSender` abstraction with a MailKit SMTP implementation and a Development-only file mode.
- Add Turkish plain text and HTML templates, encoding every value.
- Application startup fails if file mode is set outside Development.

## Acceptance criteria
- [ ] Turkish subjects and bodies stay correct with UTF-8.
- [ ] SMTP failures are logged without tokens or full addresses and do not expose details to users.
- [ ] CRLF in input cannot inject headers.
- [ ] Credentials come only from secrets or environment.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
