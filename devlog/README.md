# Geliştirme Günlüğü

Her görev çalıştırması için `entries/` altında ayrı bir Türkçe kayıt tutulur. `DECISIONS.md` kalıcı kararları içerir.

Dosya adı: `YYYY-MM-DD-T-XXX.md`

Şablon:

```
# T-XXX Başlık
- Tarih:
- Ajan ve model:
- Sonuç: Tamamlandı | Engellendi
- Yapılanlar:
- Çalıştırılan testler ve sonuç:
- Güvenlik notları:
- Sonraki görev için notlar:
```
