# T-019: Editable legal documents

- Depends on: T-016
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Provide editable KVKK and legal pages.

## Scope
- Seed Turkish draft templates marked `Taslak` for: KVKK Aydınlatma Metni, Açık Rıza Metni, Çerez Politikası, Kullanım Koşulları, Gizlilik Politikası.
- Add admin editor with versioning: each save creates a new version, old versions are retained and readable.
- Add public pages for the current published version and footer links.
- Support a safe format only: `#` headings, `-` lists, paragraphs, all encoded; no raw HTML.
- Add editable data controller fields: title, address, contact e-mail, KEP, shown through placeholders.

## Acceptance criteria
- [ ] Non-admins cannot edit.
- [ ] Script or HTML renders literally.
- [ ] Publishing keeps prior versions unchanged.
- [ ] Turkish text round-trips correctly.
- [ ] Admin dashboard warns while any document or controller field is still a draft.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
