# T-016: Site settings and branding resolver

- Depends on: T-015
- Developer model: sonnet
- Test model: haiku
- Review: sonnet
- Human gate: no

## Goal
Make branding configurable through appsettings or the database.

## Scope
- Add `SiteSettingsRepository` with an allowlist of keys and a cache invalidated on writes.
- Add `IBrandingProvider` using PLAN section 4 precedence, consumed by the layout for title, logo, favicon, footer.

## Acceptance criteria
- [ ] Precedence holds in all three states, including clearing a portal value.
- [ ] appsettings changes appear without restart when no portal value exists.
- [ ] Unknown keys cannot be written.
- [ ] Title and footer are HTML-encoded.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
