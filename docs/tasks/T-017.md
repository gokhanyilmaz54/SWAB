# T-017: Branding portal and secure upload

- Depends on: T-016
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Let admins change branding in the portal.

## Scope
- Add admin branding page: title, footer, logo and favicon upload, reset to appsettings.
- Implement upload rules from PLAN section 6, and public `/branding/logo` and `/branding/favicon` endpoints.
- Log changes without file contents.

## Acceptance criteria
- [ ] SVG, HTML renamed as PNG, oversized, and empty files are rejected.
- [ ] Path traversal in file names has no effect; stored names are random.
- [ ] Responses include correct content type and nosniff.
- [ ] Non-admins cannot change anything.
- [ ] Replaced files are removed only after the new file is saved.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
