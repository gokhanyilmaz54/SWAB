# T-009: Login, logout and lockout

- Depends on: T-008
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Provide secure sign-in and sign-out.

## Scope
- Add login and POST logout pages.
- Require confirmed e-mail; use a generic failure message for every failure.
- Validate return URLs and apply rate limits.
- Log success, failure, and lockout by UserId when known.

## Acceptance criteria
- [ ] Cookie has `__Host-` prefix, Secure, HttpOnly, SameSite=Lax.
- [ ] The 5th failure locks the account for 15 minutes.
- [ ] Unconfirmed, unknown, wrong-password and locked accounts show the same message.
- [ ] External return URLs are rejected.
- [ ] Logout by GET does not work.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
