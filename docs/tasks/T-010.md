# T-010: Password recovery and profile

- Depends on: T-009
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Complete basic account management.

## Scope
- Add forgot password, reset password, change password and display name edit.
- Use a generic forgot password response and rate limits.
- Add `no-store` cache header to account pages with tokens.

## Acceptance criteria
- [ ] Reset token works once and expires after 1 hour.
- [ ] Reset or change updates the security stamp and ends other sessions.
- [ ] Change password requires the current password.
- [ ] Users can only edit their own profile.
- [ ] No token appears in logs or leaks through Referer.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
