# T-011: Admin area and bootstrap command

- Depends on: T-009
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Create the protected admin area and the first administrator.

## Scope
- Add `create-admin` command per PLAN section 2; it never prints or logs the password.
- Add an `Admin` area with the `AdminOnly` policy and a simple dashboard.

## Acceptance criteria
- [ ] Anonymous users are redirected, and normal users get 403 on every admin route.
- [ ] A reflection test confirms every admin controller has the policy.
- [ ] The command is idempotent and rejects weak passwords.
- [ ] Admin menu hiding is not the only protection.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
