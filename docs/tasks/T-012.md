# T-012: Two-factor authentication

- Depends on: T-010
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Add TOTP 2FA with recovery codes.

## Scope
- Implement authenticator key, two-factor and recovery code stores; encrypt key and codes at rest with Data Protection.
- Add enable, verify, disable, regenerate recovery codes, and the login second step.
- Render the QR code on the server as an image with QRCoder and also show the manual key, with no inline script.
- Add `Security:RequireAdminTwoFactor` (default true outside Development): admins must enroll before using the Admin area.
- Show recovery codes once, with `no-store`.

## Acceptance criteria
- [ ] A valid code signs in; wrong and reused codes fail.
- [ ] Second step attempts count toward lockout and are rate limited.
- [ ] Each recovery code works once.
- [ ] Enabling and disabling require the password and update the security stamp.
- [ ] Keys and codes are unreadable in the database and never logged.
- [ ] An admin without 2FA cannot reach admin pages when required.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
