# T-013: E-mail change and session control

- Depends on: T-010
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Let users change e-mail safely and end their sessions.

## Scope
- Add e-mail change requiring current password; confirm through a link sent to the new address.
- Notify the old address after a change.
- Add sign out from all devices.

## Acceptance criteria
- [ ] E-mail does not change until the token is confirmed.
- [ ] The response does not reveal whether the new address is in use.
- [ ] A token works only for that user and that address.
- [ ] Stamp changes end other sessions.
- [ ] Requests are rate limited and addresses are not logged.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
