# T-023: Announcement reading and replies

- Depends on: T-022
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Let users read published announcements and reply.

## Scope
- Add announcement list and detail pages for signed-in users, with paginated replies.
- Add reply creation with rate limits; users can soft delete their own replies, admins any reply.
- Show display names, never e-mail addresses.

## Acceptance criteria
- [ ] Draft and deleted announcements return 404 to normal users, including replies posted to them.
- [ ] A user cannot delete another user's reply by changing the id.
- [ ] Reply length and empty input are validated on the server.
- [ ] XSS payloads render encoded.
- [ ] Reply text is not logged.
- [ ] Dapper paging uses parameters.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
