# T-022: Announcement management

- Depends on: T-015
- Developer model: sonnet
- Test model: haiku
- Review: sonnet
- Human gate: no

## Goal
Let admins publish announcements.

## Scope
- Add admin list, create, edit, publish, unpublish and soft delete, with pagination.
- Render plain text with encoded line breaks.

## Acceptance criteria
- [ ] Only admins can use each action, including direct POST.
- [ ] Length limits are enforced on the server.
- [ ] HTML or script in Turkish text shows literally.
- [ ] Delete is soft and uses POST.
- [ ] Changes are logged without body text.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
