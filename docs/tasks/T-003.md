# T-003: Structured logging and error handling

- Depends on: T-001
- Developer model: sonnet
- Test model: haiku
- Review: none
- Human gate: no

## Goal
Add Serilog, runtime-changeable levels from appsettings, correlation ids, and safe errors.

## Scope
- Configure Serilog per PLAN section 7: console and rolling JSON file.
- Add `LogLevelController` using `IOptionsMonitor`; appsettings level changes apply without restart. Design it to accept a portal override later.
- Add correlation id middleware and request logging without query string.
- Add a global exception handler and a Turkish error page showing only the correlation id.

## Acceptance criteria
- [ ] Changing configured level at runtime changes emitted levels without restart.
- [ ] Query strings do not appear in request logs.
- [ ] An unhandled exception gives an error page with no stack trace outside Development and logs Error with the correlation id.
- [ ] Log files are UTF-8 and keep Turkish characters.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
