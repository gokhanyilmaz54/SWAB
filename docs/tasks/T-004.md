# T-004: Security pipeline baseline

- Depends on: T-001, T-003
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Apply application-wide protection before any feature exists.

## Scope
- Implement from PLAN section 6: fallback authorization policy, global antiforgery, security headers and CSP, HSTS and HTTPS redirection, forwarded headers from configured proxies, named rate limit policies.
- Configure Data Protection key persistence.
- Keep each concern in `Infrastructure/Security` and call through extension methods.

## Acceptance criteria
- [ ] All listed headers appear on responses, and CSP has no `unsafe-inline`.
- [ ] A new endpoint without `[AllowAnonymous]` denies anonymous users.
- [ ] POST without antiforgery token returns 400.
- [ ] Exceeding a limit returns 429.
- [ ] Spoofed forwarded headers from an untrusted source are ignored.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
