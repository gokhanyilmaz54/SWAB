# T-002: Database foundation and schema

- Depends on: T-001
- Developer model: sonnet
- Test model: haiku
- Review: none
- Human gate: no

## Goal
Provide connections, the migration runner, and the initial schema.

## Scope
- Add `IDbConnectionFactory` (connection string `ConnectionStrings:Default` from secrets or environment).
- Add the migration runner and `dotnet run -- migrate`; applied scripts tracked in `SchemaVersions`, each in a transaction.
- Add `db/migrations/0001_initial.sql` with all PLAN section 5 tables, constraints, and indexes, and seed the `Admin` role.
- Add the test database fixture from PLAN section 9 (`SWAB_TEST_SQL`; each run creates and drops its own uniquely named test database).

## Acceptance criteria
- [ ] Migrating an empty database succeeds, and a second run changes nothing.
- [ ] A failing script rolls back and is not recorded.
- [ ] Web startup never runs migrations.
- [ ] Round trip of `ÇĞİÖŞÜçğıöşü` through NVARCHAR passes.
- [ ] Normalized columns use the BIN2 collation.

## Out of scope
- Scripts that drop or delete anything.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
