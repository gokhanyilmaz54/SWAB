# T-020: Consent records and cookie notice

- Depends on: T-019, T-008
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Record legal acknowledgements and inform about cookies.

## Scope
- Registration shows a separate, unticked acknowledgement for terms and an aydınlatma link; explicit consent stays separate and is never bundled.
- Store `UserConsents`: user, document, version, time.
- Publishing with `RequiresReacceptance` makes users accept on next sign-in.
- Add a cookie notice describing only strictly necessary cookies; use a small external script or a form with no tracking.

## Acceptance criteria
- [ ] Registration fails on the server without required acknowledgement.
- [ ] Records show the exact version.
- [ ] Re-acceptance cannot be bypassed by direct URLs.
- [ ] No analytics or third-party request exists on any page.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
