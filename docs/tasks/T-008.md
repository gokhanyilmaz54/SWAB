# T-008: Registration and e-mail confirmation

- Depends on: T-005, T-006, T-007
- Developer model: sonnet
- Test model: sonnet
- Review: sonnet
- Human gate: no

## Goal
Let users register and confirm their e-mail.

## Scope
- Add register, confirm and resend confirmation pages with Turkish text.
- Apply rate limits.
- Use the same response for existing and new e-mails; send an informational mail to an existing account.

## Acceptance criteria
- [ ] Responses are indistinguishable for existing and new e-mails.
- [ ] Invalid or expired tokens fail with a generic message.
- [ ] Weak passwords and invalid input are rejected on the server.
- [ ] Turkish display names work, and HTML in names renders encoded.
- [ ] No token or address appears in logs.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
