# T-018: Log level portal

- Depends on: T-016, T-003
- Developer model: sonnet
- Test model: haiku
- Review: sonnet
- Human gate: no

## Goal
Let admins change log detail in the portal without restart.

## Scope
- Add admin page showing effective and source level for each category, with set and reset controls.
- Connect `LogLevelController` to `SiteSettings`; load overrides at startup.
- Allow only the levels and categories in PLAN section 7.

## Acceptance criteria
- [ ] A change takes effect immediately without restart and is logged with admin UserId.
- [ ] Reset returns to the appsettings value.
- [ ] Invalid levels or categories are rejected on the server.
- [ ] Non-admins cannot access it.
- [ ] At Debug, passwords, tokens and reply text still do not appear in logs.

## Always applies
`CLAUDE.md` rules, `docs/PLAN.md`, and `dotnet build -warnaserror` plus `dotnet test` passing.
